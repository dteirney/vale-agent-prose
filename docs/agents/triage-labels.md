# Triage labels

The skills name five triage roles. This table maps each role to the label string this
repository's issue tracker uses.

| Role              | Label here        | Meaning                                            |
| ----------------- | ----------------- | -------------------------------------------------- |
| `needs-triage`    | `needs-triage`    | A maintainer has to assess the issue.            |
| `needs-info`      | `needs-info`      | The issue waits on its reporter for more detail. |
| `ready-for-agent` | `ready-for-agent` | An unattended agent can build it as written.     |
| `ready-for-human` | `ready-for-human` | A person has to build it.                        |
| `wontfix`         | `wontfix`         | Nobody acts on the issue.                        |

When a skill names a role, use the label string from this table. Edit the middle column to
match the labels the tracker already uses.
