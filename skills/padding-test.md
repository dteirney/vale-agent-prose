# The padding test

An alert says a line matched a pattern. This test asks whether the flagged words do work in the line.

Delete the flagged words in your head and read the line back. Where it still says the same thing, the words were padding, and the rule was right about the line. Where the meaning moved, the words were doing work, and the rule was wrong about it.

A rule flags "usually" in "a hedge is usually the point" as a filler adverb. Without it the line claims more than the writer meant, so the word does work. The same rule flags "just" in "just check the output", which says nothing, so it's padding.

An alert from a metric rule flags no words, so the test can't judge it.
